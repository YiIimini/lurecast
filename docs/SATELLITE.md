# 历史影像 · 水下结构（Sentinel-2）

「水下结构」唯一能规模化拿到的免费路线：**同一片水面在不同水位时期拍到的影像**。
代码在 `src/lib/sat.ts`（由老壳 `assets/sat.js` 机械迁移后重做），geotiff.js 懒加载（`src/lib/geotiff-loader.ts`）。

## 流程

1. **找枯水期**：跨 3 年按月分散抽 3 期 Sentinel-2 L2A（云量 <20%），对每期只读你周围 1.2 km 那一小块算水体占比
   （只读 SCL 一个文件），占比最低的那期＝库水位最低＝库底露出最多。
2. **真彩 + 水深**：读枯水期的 TCI（`visual`，红绿蓝在同一个 COG 里）：真彩图（枯水露出的老河床、路基肉眼可见）
   和蓝绿比水深图（Stumpf 法，清水前提下越浅越偏青）。水体掩膜用 SCL 的 class 6，比 NDWI 阈值可靠。
3. **结构候选点**：蓝绿比按 16×16 网格统计，与 3×3 邻域比较，挑「本格明显更浅」的块 —— 水下浅脊、硬底、砂石脊。
   这些点落到地图上，**离它 250 m 内的钓点结构分 +8**，理由写「历史影像：水下浅脊/硬底」。
4. **两期水位差**：再读一期丰水期的掩膜，「枯水露出 / 丰水淹没」的比例就是这段水位变动幅度。

## 影像面板

「影像 → 分析影像」之后只有**一张主影像**（铺满卡片宽度），上面是模式切换 + 期次列表 + 窗口重读：

- **三种模式**：水深（蓝绿比）/ 真实影像 / 水体掩膜。
- **期次**：换一期只重读那一期，主图与结构候选点一起更新。
- **窗口**：0.3–3 km 可重读（默认 0.9 km）。窗口越小越细，但 Sentinel-2 物理上限就是 10 m。
- 图下统计：主影像 / 对比期（含云量与水体占比）、采样像素与 m/px、异常点数量。
- **重复打开不重下**：结果按「中心点 + 半径 + 云量阈值」缓存在模块里，切页签回来再点一次是 1 秒 / 0 次网络请求；
  只有按钮变成「重新分析」才真的重跑（那时也通常只要 1 次 STAC 请求，COG 的块已按 URL 缓存）。

## 工程上的关键（踩过的坑，别踩回去）

- `GeoTIFF.fromUrl(href, { allowFullFile: false })`：不加可能整幅 190 MB 波段全下。
- 读取必须用**像素 window**，不能用 `bbox`：bbox 路径实测单次 42 秒（会拉整幅），window 只要 0.5–1 秒。
- 按目标分辨率**挑金字塔层级**：2.4 km 窗口要 64 px 就用 40 m 那层，别拿 10 m 全分辨率去凑。
- y 轴方向：origin 是左上（北）角，行号 = (origin_y − 纬度对应 northing) / 分辨率。
- **地理参考用 STAC 的 `proj:transform` / `proj:shape`**，别信文件里的 GeoKey：`TCI.tif` 没有 GeoKey，
  `getOrigin()` 返回 `[0,0]`，窗口会整块算到影像外（表现是「采样 1×1」）。缺失时借同景兄弟波段的 transform。
- **参数顺序**：`Sat.analyse(lon, lat, opts)`。传反会检索到地球另一边的瓦片，同样是「采样 1×1」。
- **慢网的第一性原理是「请求次数 × 延迟」**：实测到 S3 首字节 3.4–4 s、吞吐 60–100 KB/s。所以
  少开文件（TCI + SCL 两个）、并行发（`Promise.all`）、`blockSize` 128 KB（512 KB 反而更慢）；整条链 90 s 硬超时。
- `datetime` 必须 RFC3339 全格式，给 `2024-01-01` 会 400。
- 界面上的画布要等 DOM：卡片是 `v-if` 切出来的，`res` 赋值后要 `await nextTick()` 再画，否则画在 300×150 的空画布上。

实测（生产构建 + 系统 Chrome，西湖 0.9 km 窗口）：网络好时 6 秒 / 11 次请求；慢网 30–46 秒；
输出 176×185 约 10 m/px、异常点 7 个、无 page error。

## 局限（卡片上也写着，不藏着）

- 蓝绿比在浑水/深水（>10–15 m）失效。
- 多云地区可能 3 年内没有可用的低云影像。
- 这仍然是「水色推断」，不是声纳测深；要真实深度就导入 Deeper 的 CSV（见 [`DEEPER-SONAR.md`](DEEPER-SONAR.md)）。
- 慢网下 90 秒会超时报错（错误提示里带建议：缩小半径或稍后重试，已下载的块会留着）。
