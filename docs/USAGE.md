# 使用说明

## 四个页签

顶部：**结论 / 钓点 / 影像 / 我的**（原来的「数据」页已并进「结论」）。

### 结论

定位后给出 6 张卡：当前位置与水域、鱼口指数、未来 24 小时、天气实况、风况与迎风岸、水位与水流。
鱼口指数卡只看结论；想查每个因子怎么打分，去「我的 → 更多 · 环境分怎么算」。

- **罗盘是动态的**：指针用 `requestAnimationFrame` 平滑追随目标风向（走最短弧，约 0.3 s），换小时不跳变；
  三根风线持续外扩，`性能优先` 下自动停。下方可点 **现在 / +1h / +3h / +6h** 看风怎么转。
- **罗盘真指北**：右上角「指北」开启后刻度盘跟着手机方向反向旋转，N 永远对着真北，指针也换算过。
  用 `deviceorientationabsolute`（iOS 走 `webkitCompassHeading`，13+ 需在点击里申请权限）；
  没有磁力计的机型显示「无磁力计」并固定朝上，不给假北。偏好存本机（`lc:compass`）。
- 数据每 10 分钟静默刷新一次（走缓存，不打断阅读）。

### 钓点

- 地图上点任意位置 → 弹出经纬度小卡 → 「设为当前位置」，直接按那个坐标重算（不用先开「找水域」）。
- 地图十字准星 = 回到我的位置（zoom ≥ 15）。
- 点地图绿点或「推荐钓点」卡片 = 设为**目标钓点**（卡上出现徽标，再点取消）。之后分享/导航/复制坐标全部指向目标点，路线也画到那里。
- 「推荐钓点」每条都带：方位标题（`千岛湖 · 西北岬角`）、坐标、岸坡与近岸水深数字、两条理由、拟饵建议。

### 影像

见 [`SATELLITE.md`](SATELLITE.md)：一张主图 + 期次/窗口切换 + 结构候选点列表。

### 我的（全部只存本机）

1. **常用地点**：保存当前位置时可填 **名称 + 描述 + 最多 6 张图片**（相册/拍照两条入口，压到 480px 只存本机）；
   列表带缩略图，点「✎」可改；点一行即切换评估位置；120 m 内重复会提示；上限 30 个。导出档案时图片一起打包。
2. **渔获档案 · 拍照解锁**：拍照或从相册选 → 压到 480px JPEG → 手动确认鱼种（**本地不做 AI 识别**，
   除非你在设置里配了视觉模型）→ 记录带上当时的鱼种/尺寸/经纬度/天气/气压/鱼口指数。上限 80 条，配额满时丢最老的照片保住记录。
3. **我的水族馆**：每解锁一个新鱼种就多一条会游的鱼，整个缸是**实景底片 + 3D 鱼**（three.js 渲染）。
   - 底景是一张真实水下照（天光、水草、沙底、藻石），在着色器里持续做折射抖动与水色吸收，
     所以画面一直在「活」，不是一张静态壁纸；
   - 鱼是写实贴图（25 种，各一张侧视 WebP，生成与抠图脚本在 `native/tools/`），贴到 3D 面片上：
     摆尾、浮沉、按水层高度游，远处自动变淡变虚（模拟水的能见度与景深），掉头会翻转，不会倒着游；
   - 鱼下方有接地阴影、河床上有缓慢移动的焦散光斑、水里有悬浮颗粒和上浮气泡、顶部有几道会晃的光柱；
   - 掉帧会自动降级（降 DPR、关颗粒/气泡/光柱）；WebGL 不可用或 3D 加载失败时**自动退回原来的 2D 画法**；
     `性能优先` 下同样降级；
   - 右上角可全屏，底部列出缸里每种鱼的名字。
4. **声呐实测水深**：导入 Deeper 导出的 CSV（格式见 [`DEEPER-SONAR.md`](DEEPER-SONAR.md)），
   地图按深度着色；与「地形结构」卡里按 DEM 外推的近岸深度是两回事。
5. **更多**：环境分怎么算 / 数据来源与局限两张长卡，默认收起。

## 分享与导航

定位卡（或目标钓点）右上「分享」：

- **高德导航 / 百度导航**：没装 App 会自动回落到网页版地图（高德链接带 `callnative=1`，装了就能拉起）。
- **分享位置**：调系统分享面板，文本 = 地名 + WGS-84 + 高德坐标 + 高德链接 + OSM 链接。
- **复制坐标**：三行文本进剪贴板。

坐标口径：应用内部（GPS / OSM / Open-Meteo）一律 **WGS-84**；国内地图要 **GCJ-02**，百度再偏 **BD-09**。
换算在**本机**完成（`src/lib/share.ts`），不上传；国外坐标自动不偏移。

## 设置

| 分组 | 能改什么 |
|---|---|
| 外观与操作 | 配色、字号、界面语言（简/繁/EN）、性能优先、背景色斑 |
| 判定口径 | 评分偏好、水温来源、卫星水面兜底、窗口期是否并入评分 |
| 地图与路线 | 底图、路线服务（OSRM / 自定义 / 关）、天地图 Key |
| 识图与助手 | 厂商、Key、模型、对话模型（可选）、测试连接 |
| 数据与版本 | 导出/导入档案、清空缓存、本机存储用量、检查更新 |

设置面板超过 90vh 时整块滚动，分组默认只展开第一组。所有弹窗/表单都是自绘的（`src/lib/ui.ts`），
没有系统 `alert/confirm/prompt`，也没有原生 `<select>`。

## 底图

默认 **OSM 中文 · 深色**（`tile.openstreetmap.de` 镜像；国内 `tile.openstreetmap.org` 常超时），
深色档是给瓦片层加反相 + 降饱和滤镜压暗。

| 预设 | 地名 | Key |
|---|---|---|
| OSM 中文 · 深色（默认）/ 浅色 | 中文 | 免 |
| Esri 影像 | 无地名，纯影像 | 免 |
| 天地图 矢量 / 影像 | 中文 | 需 tk |
| CARTO Dark / Positron / Voyager | 英文居多 | 需 Key（不带会返回「API KEY REQUIRED」占位图） |
| 自定义 URL | 看接什么 | — |

不接 Google 卫星：瓦片接口要付费 Key，直连 `mt1.google.com` 违反 ToS 且国内有 GCJ-02 偏移。
确有 Key 就走「自定义 URL」，费用与合规自负。

## 三条命的自愈

1. **地名搜索**：主源 OSM Nominatim（实测 12 个国内大湖 12/12 命中），Open-Meteo 兜底；
   搜到大湖时不把你丢在湖心，而是落到**离你最近的那一侧岸边**。
2. **岸线数据**：Overpass 是免费公共服务，实测同一分钟内 `overpass-api.de` 200 / `private.coffee` 500 /
   `kumi` 500 / `mail.ru` 504 轮换；所以按顺序自动切换，失败端点冷却 3 分钟，再用 12 小时长缓存兜底。
3. **卫星水面兜底**：全挂时用 Sentinel-2 水面掩膜提岸线点（NDWI + 边界像素 + 200 m 稀疏化）。
   实测把 Overpass 全部拦掉后 15 秒出 24 个钓点，卡片标「卫星水面」。

## 加载与缓存

逆地理（Nominatim）不重试 + 6 秒上限，且不阻塞首屏；气象先出，海况/汇流/地名到了再增量刷新。
缓存 TTL 与二次打开实测见 [`DATA-SOURCES.md`](DATA-SOURCES.md)。
