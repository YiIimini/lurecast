# 界面语言：简 / 繁 / EN

设置 → 外观与操作 → 界面语言。三种语言覆盖**整页文案**：按钮、说明、提示气泡、弹窗、toast、地图图例都会切；
地名与你自己写的备注**不会**被翻译（它们不在对照表里）。选择存本机（`lc:lang`）。

## 实现方式

没有给每处 Vue 模板加 `t()`（那要改几百处），而是**按原文对照表替换 DOM**：

- `src/lib/i18n-phrases.ts`：**276 条**可见文案（key = 简体原文，值 = `[繁体, English]`）
  + **11 条**带数字的动态模板（`0 / 25 种`、`云量 2%`、`水体占比 67% · 云 2%`、`约 10 m/px`、`86 分`、`3 小时后` …）。
- `src/lib/i18n.ts`：
  - `applyDom()` 遍历文本节点与 `placeholder/title/aria-label/data-tip/alt`，命中即替换；
  - **整句匹配**：元素子节点全是 inline 标签时，按整个 `textContent` 再试一次（被 `<b>实测</b>`、`<code>bathymetry.csv</code>`
    切开的句子只能这么翻），原文 `innerHTML` 存 WeakMap，切回简体时原样还原；
  - `MutationObserver` 盯 `body`（80 ms 合并、队列跨回调累积），页签切换 / 弹窗 / toast 里新出现的文案也会翻；
  - 跳过 `<input>/<select>/<textarea>` 的内容（只翻它们的 placeholder）。
- `main.ts` 在 `app.mount()` 之后再 `I18N.apply()`：挂载前 body 还是空壳，observer 也起不来。

## 维护文案

脚本在 [`tools/i18n/`](../tools/i18n/README.md)：

```powershell
npm run build
python tools/i18n/collect_visible.py     # 抓四页签 + 弹窗的可见中文 → visible.json
python tools/i18n/list_missing.py        # 看还差哪些英文
#  …把新条目译好补进 tools/i18n/en.py…
python tools/i18n/gen_phrases.py         # 生成 src/lib/i18n-phrases.ts
npm test                                 # 覆盖度守卫会拦住漏译
```

繁体由 OpenCC `s2twp` 生成（台湾正体 + 台港用词），英文人工翻。

## 验证与限制

- 英文下逐页签扫全部文本节点 + 属性：**0 条中文残留**（含卫星卡出图后的界面）；繁体整页正常；切回简体 `innerHTML` 还原。
- 单测 5 条钉对照表：两列非空、英文列无中文、模板 `$n` 不越界、每条模板能匹配真实文案、
  `visible.json` 里每条都能命中对照表或模板（漏译直接红）。
- 限制：改文案后要重跑上面四步；整句替换会抹掉句内 `<b>/<code>` 强调（切回简体才恢复）。
